## 摘要
在外部环境中进行大规模生物特征识别需要同时满足两个特性：生物特征模板和查询在计算过程中必须保持加密状态，并且由不可信计算节点生成的加密相似性输出在发布任何应用结果之前必须可验证正确。现有的基于FHE的生物特征系统主要解决机密性问题，而实际可验证性在底层的加密1:N匹配层中引入了两个瓶颈：高旋转和高带宽的相似性评估，以及证明重复同态相似性轨迹的高成本。我们提出BioZKFHE，一个通过可验证同态相似性评估实现可扩展加密生物特征识别的框架，该框架将BGV同态计算与委员会中介的证明打开/解密以及打开证明批次的智能合约验证相结合。为了减少加密存储并避免高旋转的加密1:N匹配，我们提出了单系数多值（SCMV）打包，通过基T展开将多个量化嵌入值绑定到每个明文条目中。为了使证明生成实用，我们提出了可并行化和可验证的相似性计算（PVSC），利用BGV的双CRT执行结构，将每个块状相似性轨迹分解为并行证明实例，这些实例在结果发布前被打开和检查。在标准格假设和明确的委员会/验证者假设下，我们分析了可恢复性、噪声增长、机密性、加密输出完整性和最终结果完整性。在FaceNet和MobileFaceNet上的实验显示，生物特征实用性接近无损，加密存储减少高达67%，对于1万到4万个模板，端到端证明验证运行时间约为22到44秒。

## Abstract
Large-scale biometric identification in outsourced settings requires two properties simultaneously: biometric templates and queries must remain protected during computation, and the encrypted similarity outputs produced by an untrusted compute node must be verifiably correct before any application result is released. Existing FHE-based biometric systems primarily address confidentiality, while practical verifiability introduces two bottlenecks in the underlying encrypted 1:N matching layer: rotation- and bandwidth-heavy similarity evaluation and the high cost of proving repeated homomorphic similarity traces. We present BioZKFHE, a framework for scalable encrypted biometric identification via verifiable homomorphic similarity evaluation that combines BGV homomorphic computation with committee-mediated proof opening/decryption and smart-contract verification of opened proof batches. To reduce encrypted storage and avoid rotation-heavy encrypted 1:N matching, we propose Single-Coefficient Multi-Value (SCMV) packing, which binds multiple quantized embedding values into each plaintext entry through base-T expansion. To make proof generation practical, we propose Parallelizable and Verifiable Similarity Computation (PVSC), which exploits the Double-CRT execution structure of BGV to decompose each blockwise similarity trace into parallel proof instances that are opened and checked before result release. Under standard lattice assumptions and explicit committee/verifier assumptions, we analyze recoverability, noise growth, confidentiality, encrypted-output integrity, and finalized-result integrity. Experiments on FaceNet and MobileFaceNet show near-lossless biometric utility, up to 67 percent encrypted-storage reduction, and about 22 to 44 seconds end-to-end proof-verified runtime for 10k to 40k templates.

## 1. 论文的核心问题与整体含义（研究动机和背景）

- **核心问题**：在基于区块链或外包云计算的生物特征识别场景中，需要同时满足两个关键需求：**机密性**（生物特征模板和查询在计算过程中必须保持加密）和**可验证性**（由不可信计算节点生成的加密相似性输出必须被证明是正确的，才能发布应用结果）。
- **现有瓶颈**：现有的全同态加密（FHE）生物特征识别系统主要关注隐私保护（针对诚实但好奇的服务器），但缺乏针对恶意服务器的可验证性。若直接添加可验证性，会引入两个主要瓶颈：
  - **旋转与带宽开销**：加密的 1:N 匹配通常需要昂贵的密文旋转和槽聚合操作，随着模板库规模增长，延迟和通信开销急剧增加。
  - **证明生成成本高**：为完整的同态相似性计算生成零知识证明（或可验证计算证明）的电路巨大，难以并行化，导致证明生成延迟过高。
- **研究意义**：提出一个可扩展的、同时提供机密性和可验证性的加密生物特征识别框架，适用于大规模外包身份识别场景（如区块链辅助的去中心化身份、反女巫攻击系统）。该框架通过优化打包和证明并行化，在实用性和安全性之间取得平衡。

## 2. 论文提出的方法论

### 核心思想
- 提出 **BioZKFHE** 框架，整合了：
  - **BGV** 全同态加密方案用于机密计算。
  - **委员会中介的证明打开/解密**：由阈值委员会（threshold committee）打开加密的证明对象，并阈值解密验证通过的密文相似性结果。
  - **智能合约验证**：智能合约负责验证打开后的证明批次，确保加密相似性输出的正确性，然后才允许最终结果发布。

### 关键技术细节

#### a. 单系数多值打包（SCMV）
- 目标：减少加密存储和消除在线相似性计算中的旋转操作。
- 方法：将多个量化后的嵌入值通过 **基 T 展开** 绑定到每个明文项的单个系数中。即每个明文条目存储 n 个用户在同一维度的值，表示为 `w = sum_{t=1}^{n} v_t * T^{t-1}`。
- 效果：一个加密块覆盖 `n * d` 个模板（d 为 SIMD 槽数），相比传统的一槽一值（n=1）方案，块数减少到原来的 1/n，从而减少存储和在线匹配轮次，且无需槽旋转。

#### b. 可并行化和可验证的相似性计算（PVSC）
- 目标：使证明生成实用化。
- 方法：利用 BGV 的 **Double-CRT** 执行结构（Residue Number System 分解 + NTT 表示），将每个块状相似性计算（乘-重线性化-累加）轨迹分解为大量小的、同构的证明实例。这些实例可以并行生成，并在委员会打开后由智能合约逐一验证。
- 证明实例类型包括：乘法正确性（R_mul）、累加正确性（R_acc）、输出一致性（R_out）和块绑定（R_bind）。
- 验证过程：委员会阈值打开加密证明 → 智能合约解析并验证打开后的证明批次 → 记录已验证的块索引 → 所有块验证通过后触发阈值解密和结果最终化。

#### c. 协议流程（算法概述）
1. **初始化**：生成 BGV 密钥对、PVSC 公共参数、委员会阈值密钥分享。
2. **会话创建**：智能合约创建包含新鲜会话 ID、加密图库快照和元数据的上下文。
3. **客户端准备**：量化并加密生物特征向量，输出查询/注册密文。
4. **绑定请求**：智能合约记录查询承诺和块承诺。
5. **块验证循环**：计算节点执行 SCMV 匹配并生成 PVSC 证明 → 委员会阈值打开证明 → 智能合约验证打开后的证明批次。
6. **覆盖门控**：仅当所有块索引被接受一次后，才允许阈值解密。
7. **阈值恢复**：委员会阈值解密相似性结果，派生最小应用输出（如登录/注册决策）。
8. **最终化**：委员会提交一致的确认，智能合约最终化。

### 安全模型
- 假设计算节点是恶意的；委员会最多可腐化 t-1 个成员（阈值t）；聚合方（relay）不可信；区块链智能合约正确执行。
- 安全目标包括 G1（生物特征机密性）、G2（加密输出完整性）、G3（最终结果完整性）。

- **缺乏与其他系统量化比较**：虽然声明非完全可比，但在结论中引用“减少 67% 存储”等优势时，未与最新的可验证 FHE 方案或纯 FHE 系统进行同等条件对比，可能影响说服力。
- **硬件限制**：所有实验仅使用 CPU，未评估 GPU 加速可行性。许多现代 FHE 库（如 HElib、SEAL）有 GPU 后端，但本文未采用。
- **安全参数实际意义**：Core-SVP 估计仅为下限，且论文使用了较保守的 Ring-LWE 到 LWE 的代理，实际安全边际可能偏紧。另外，PVSC 的后端（[32]）的模块格参数未单独重新评估。
- **生物特征实验局限性**：仅使用两个预训练模型（FaceNet、MobileFaceNet），且评估数据集为 LFW/CASIA-WebFace 交叉使用，但未报告识别精度绝对数值的具体测试集构建细节（如 LFW 官方协议与本文自定义划分的区别）。未考虑相似度阈值优化（论文使用了固定阈值）。
- **扩展性讨论不足**：方案目前仅适用于深度为 1 的内积相似度计算（旋转、模切换、bootstrapping、top-k 等被排除在验证范围外）。虽然论文讨论了扩展路径，但未实现或评估多层电路场景。
- **委员会和区块链依赖**：安全性依赖于阈值诚实假设和区块链正确性，实际部署中可能存在 liveness 攻击、贿赂、跨链问题等，论文未深入分析。
- **证明体积较大**：即使经过并行化，一个块（FaceNet n=3）的打开证明大小达约 8.12 MiB，对于大数据库（百万级）会话累计可达数百 GiB，目前仅适合低吞吐场景。
