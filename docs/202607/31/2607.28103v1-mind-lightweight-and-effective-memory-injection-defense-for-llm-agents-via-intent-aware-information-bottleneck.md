## 摘要
基于记忆增强的LLM智能体容易受到记忆注入攻击：智能体可能检索到来自攻击者的恶意记忆，使其行为偏离初始用户意图，最终导致任务失败。然而，现有的防御机制要么计算成本高，要么在多轮上下文中存在信息冗余问题。为应对这些挑战，我们提出了记忆意图感知神经去噪（MIND），一种用于记忆注入攻击的轻量级防御框架。我们的初步分析表明，良性轨迹与恶意轨迹在初始用户意图与后续行为之间表现出可区分的关系。基于这一观察，MIND采用意图感知信息瓶颈（IB）从初始意图和逐轮行为中提取紧凑的意图-行为表示。IB在过滤任务无关和重复信息的同时，保留与意图相关的跨轮攻击信号，轻量级检测器从所得表示中识别恶意记忆。因此，MIND在多轮上下文中减轻信息冗余，同时避免重复LLM审计的开销。大量实验表明，MIND降低了攻击成功率，同时保持了任务准确性和推理效率。值得注意的是，在ReAct-StrategyQA上，MIND将平均ASR-r和ASR-a分别降低了55.4%和55.3%，同时与未防御的智能体在平均准确率和延迟上相匹配。

## Abstract
Memory-augmented LLM-based agents are vulnerable to memory injection attacks: Agents may retrieve poisoned memory from attackers, which diverts their behavior from initial user intent and finally causes task failure. However, existing defense mechanisms either incur high computational cost or suffer from information redundancy in multi-turn contexts. To address these challenges, we propose Memory Intent-Aware Neural Denoising(MIND), a lightweight defense framework for memory injection attack. Our preliminary analysis reveals that benign and poisoned trajectories exhibit distinguishable relationships between the initial user intent and subsequent behavior. Building on this observation, MIND employs an intent-aware Information Bottleneck(IB) to extract compact intent--behavior representations from the initial intent and turn-level behavior. The IB preserves intent-relevant cross-turn attack signals while filtering task-irrelevant and repetitive information, and a lightweight detector identifies malicious memories from the resulting representations. As such, MIND mitigates information redundancy in multi-turn contexts while avoiding the overhead of repeated LLM auditing. Extensive experiments show that MIND reduces attack success rates while preserving task accuracy and inference efficiency. Notably, on ReAct-StrategyQA, MIND reduces mean ASR-r and ASR-a by 55.4% and 55.3%, respectively, while matching the undefended agent in average accuracy and latency.

### 一、核心问题与整体含义（研究动机与背景）

- 记忆增强的 LLM 智能体依靠外部检索式记忆系统来支持长程任务，但攻击者可通过**记忆注入**（如 AgentPoison、MINJA、PoisonedRAG 等）在记忆库或检索语料中植入恶意记录。一旦被检索，这些记录会逐步使智能体行为偏离初始用户意图，导致任务失败甚至产生有害输出。
- 现有防御机制存在两大挑战：
  - **高计算成本**：基于 LLM 推理审计的防御（如 A-MemGuard、LLM Auditor、Sequential Monitor）需要反复调用 LLM，在长轨迹中开销累积严重。
  - **多轮上下文信息冗余**：轻量级多轮检测器虽降低了成本，但完整轨迹中包含大量与任务无关和重复的信息，容易掩盖攻击信号，削弱防御效果。
- 论文提出 **MIND（Memory Intent-Aware Neural Denoising）**，目标是在保持任务准确率和推理效率的同时，以轻量方式有效防御记忆注入攻击。

### 二、方法论：核心思想、关键技术细节与流程

- **核心思想**：初步分析发现，良性轨迹与恶意轨迹在**初始用户意图与后续行为之间的关系**上具有可区分性——内存注入会使智能体行为逐步偏离初始意图。基于此，MIND 利用**意图感知的信息瓶颈（IB）**提取紧凑的“意图–行为”表示，过滤任务无关和重复信息，保留跨轮次攻击信号，再用轻量检测器识别恶意记忆。
- **技术流程**：
  1. **轨迹表示提取**：使用预训练 LLM（冻结的 Llama-3.1-8B-Instruct）提取每个回合的 `last-token hidden state` 作为行为表示，初始用户查询表示作为意图锚点；对每个回合构造输入 `[h0; ht]` 和锚点 `h0`，并按检索记忆是否包含恶意记录标注标签。
  2. **信息瓶颈编码器（IB Encoder）**：
     - 目标函数为 `min I(Z;X) − α·I(Z;Y)`，即压缩输入并保持与标签的相关性。
     - 用变分方法近似 `I(Z;X)`，通过 KL 散度上界（假设高斯后验与标准正态先验）实现，并用重参数化技巧保证可微。
     - `I(Z;Y)` 通过**意图对齐损失**近似：将输入和锚点编码到同一空间，拉近良性表示与锚点距离，推远恶意表示（带边际）。
  3. **轻量多超平面分类器**：在 IB 编码后的潜在表示上，使用 **K 个超平面**构成分段决策区域，分别惩罚良性样本落在任一超平面之外、恶意样本全部落在内部，以捕捉多样的攻击模式。
  4. **总体训练目标**：组合分类损失、KL 压缩损失和意图对齐损失，联合优化编码器与分类器参数。
- **推理时**：MIND 在检索后对每条记忆进行评分过滤，仅允许“良性”记忆进入智能体上下文或写入记忆库，无需反复调用 LLM 审计。

### 三、实验设计

- **数据集与场景**：
  - 训练：EHR（电子健康记录）和 QA 智能体轨迹。
  - 评估：跨域迁移到 **ReAct-StrategyQA** 和 **MMLU** 两个 benchmark。
  - 检索器：BGE-large-en 嵌入模型，每个回合检索 5 条记忆。
  - 攻击方法：**AgentPoison**（直接注入）和 **MINJA**（间接注入/仅查询交互）。
- **骨干模型**：DeepSeek-V4、GPT-4o-mini、Llama-3.1-8B-Instruct、Qwen3-8B-Instruct，共四种不同规模与来源的模型。
