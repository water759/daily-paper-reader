## 摘要
联邦学习使多个机构能够在不交换原始临床脑电图数据的情况下训练共享模型，但它并不能完全防止来自个体模型更新的隐私泄露。本文提出了一种针对临床脑电图数据的隐私保护联邦学习框架，以基于掩码的安全聚合作为核心保护机制。该框架结合了基于图的通信、阈值秘密共享、抗掉线聚合、局部更新裁剪、可选的基于布隆过滤器的隐私保护记录链接初始化模块，以及基于辅助公证人的可验证性。它同时支持半诚实和恶意聚合设置，并使用Flower联邦学习框架实现。在模拟的跨孤岛医疗场景中，使用TUH脑电图派生数据在不同的客户端配置下评估了安全聚合变体。在所述假设下，安全变体对聚合服务器隐藏了个体更新。结果表明，这些变体与联邦模型训练兼容，尽管恶意设置保障措施和轻量级一致性检查机制带来了额外的计算、通信和轮次持续时间开销。半诚实变体在安全配置中提供了最低的开销，而恶意和辅助公证人变体以更高的成本提供了更强的一致性、完整性和轻量级验证支持。

## Abstract
Federated learning enables multiple institutions to train shared models without exchanging raw clinical EEG data, but it does not fully prevent privacy leakage from individual model updates. This paper presents a privacy-preserving federated learning framework for clinical EEG data using masking-based secure aggregation as the core protection mechanism. The framework combines graph-based communication, threshold secret sharing, dropout-resilient aggregation, local update clipping, an optional Bloom filter-based privacy-preserving record-linkage initialization module, and auxiliary-notary-based verifiability. It supports both semi-honest and malicious aggregation settings and is implemented using the Flower federated learning framework. The secure-aggregation variants are evaluated in a simulated cross-silo healthcare setting using TUH EEG-derived data under different client configurations. Under the stated assumptions, the secure variants hide individual updates from the aggregation server. The results show that these variants remain compatible with federated model training, although malicious-setting safeguards and lightweight consistency-checking mechanisms introduce additional computation, communication, and round-duration overhead. The semi-honest variant provides the lowest overhead among the secure configurations, while malicious and auxiliary-notary variants offer stronger consistency, integrity, and lightweight verification support at higher cost.

## 1. 核心问题与整体含义

- **研究动机**：联邦学习（FL）允许医疗机构在不共享原始临床脑电图（EEG）数据的情况下协作训练模型，但个体模型更新仍可能通过梯度重构、推理攻击等方式泄露患者隐私。临床 EEG 数据具有高敏感性、强异质性，且跨机构集中化受法规和成本限制，因此需要隐私保护机制。
- **核心问题**：如何在跨孤岛临床 EEG 联邦学习中，使聚合服务器只能恢复客户端更新的聚合结果，而无法获知任何单个客户端的明文更新，同时兼顾通信开销、客户端掉线和潜在的服务器恶意行为。
- **整体含义**：论文提出了一个基于掩码安全聚合（masking-based secure aggregation）的完整框架，整合图通信、阈值秘密共享、抗掉线恢复、更新裁剪、恶意设置一致性检查、辅助公证人可验证性以及可选的隐私保护记录链接模块，为临床 EEG 跨机构协作提供了一种可配置威胁模型的实用方案。

## 2. 方法论

- **核心思想**：采用掩码机制隐藏个体更新——每个客户端在本地对更新进行裁剪、量化，然后叠加自掩码和与邻居协商的成对掩码；成对掩码在聚合时相互抵消，自掩码通过秘密共享恢复，使服务器只能得到全部存活客户端的聚合结果。
- **关键技术细节**：
  - **图通信**：使用稀疏图代替全连接掩码，每个客户端只与固定数量的邻居通信，降低通信成本，同时保证掉线恢复的连通性。
  - **阈值秘密共享**：客户端将自掩码种子和用于成对掩码的私钥通过 Shamir 秘密共享分发给邻居，服务器在需要时收集足够份额恢复掩码，从而处理客户端掉线。
  - **更新裁剪与量化**：对局部更新进行 ℓ2 裁剪（τ = 0.75），再以尺度因子 sQ = 2^22 量化为模 M = 2^32 的整数域，支持聚合后的无符号整数表示和带符号反量化。
  - **掩码构造**：客户端 i 上传的掩码向量形如 yi = zi + F(bi) − Σai,j + Σai,j (mod M)，其中 F 为伪随机生成器，ai,j 为与邻居的成对掩码。
  - **聚合与恢复**：服务器依次移除存活客户端的自掩码和掉线客户端产生的残留成对掩码，得到整数聚合 YQ，再经带符号解释和反量化得到实数聚合，归一化后更新全局模型。
  - **恶意设置扩展**：使用 Merkle 树承诺绑定公共密钥、客户端验证 Merkle 证明、签名包含消息和确认消息、以及阈值 p 控制恢复份额释放，减少服务器提供不一致参与视图或伪造参与的能力。
  - **辅助公证人（AN）可验证性**：AN 发布公共随机种子，客户端计算低维线性验证标签 ⟨u, z⟩ mod q（q = 2^61 − 1），AN 聚合标签后，客户端检查重构聚合是否与标签一致，从而轻量验证聚合一致性。
  - **布隆过滤器记录链接**：可选预处理模块，用 HMAC 和布隆过滤器编码本地标识符，服务器基于 Dice–Sørensen 相似度进行隐私保护重复记录匹配，但不上传明文标识符。
- **四个协议变体**：
  - Π1：半诚实设置，图通信 + 成对掩码 + 自掩码 + 秘密共享 + 掉线恢复。
  - Π2：恶意设置，在 Π1 基础上增加 Merkle 承诺、签名、确认和一致性检查。
  - Π3：半诚实 + 辅助公证人可验证性。
  - Π4：恶意 + 辅助公证人可验证性。

## 3. 实验设计

- **数据集**：TUH EEG 语料派生子集，含 2,500 个 EDF 文件（1,250 正常 / 1,250 异常，约 50 GB），重采样至 100 Hz，19 通道，10 秒窗口，按通道归一化，仅用于正常/异常二分类。
- **模型与训练**：1D CNN（3 个卷积层，60,034 参数），交叉熵损失，Adam 优化器，学习率 0.0005，batch size 16，每客户端 2 个本地 epoch，总共 100 轮联邦学习。
- **客户端配置**：
  - 10 客户端：每客户端 250 个文件；
  - 40 客户端：从 70 个客户端文件夹中每轮选 40 个，每文件夹 30 个文件；
  - 70 客户端：从 140 个文件夹中选 70 个，每文件夹 18 个文件。
- **对比方法**：
  - 基线 FedAvg（无安全保护）；
  - 基础 SecAgg（Bonawitz 等原始掩码安全聚合，密集通信，作为比较）；
  - 提出的四个变体 Π1–Π4。
- **评估指标**：聚合时间、服务器侧协议时间、客户端侧协议时间、训练/评估时间、100 轮累计轮时长、估计通信量、分布式评估准确率。
- **协议参数**：图度 k 分别为 5/9/11（10/40/70 客户端），阈值 t 分别为 3/5/6；基础 SecAgg 阈值分别为 6/21/36；掉线容忍 δ = 0.1，验证向量数 v = 5，裁剪界 τ = 0.75，量化域 M = 2^32，验证模 q = 2^61 − 1。

## 6. 主要结论与发现

- 在所声明的假设（足够活跃客户端、非共谋等）下，安全变体能够对半诚实服务器隐藏个体更新，并完成正确聚合。
- 提出的安全聚合变体与联邦模型训练兼容，但恶意设置和辅助公证人设置会显著增加计算、通信和轮时长开销。

## 8. 缺点与局限性

- **安全性假设较强**：所有协议都依赖于“服务器与客户端不共谋”“活跃客户端数量足够”等假设；一旦服务器与部分客户端合谋，掩码秘密共享可能被绕过，隐私保证随之瓦解。
- **恶意模型覆盖不完整**：Π2 和 Π4 虽增强了服务器行为一致性，但并未对恶意客户端投毒、模型替换、数据中毒等攻击进行建模或防御；论文只关注“服务器能否窃取个体更新”，未验证聚合结果的鲁棒性。
- **实验未注入故障与攻击**：没有实际模拟客户端掉线、延迟、恶意服务器伪造活动集或恶意客户端篡改标签，导致掉线恢复和一致性检查机制只做了理论正确性验证，缺乏压力测试。
- **性能评估基准粗糙**：训练与协议耗时来自单机模拟（Flower + Ray），并非真实多机网络环境；通信量仅按预算公式估算，未测量实际字节流，难以反映真实带宽和延迟影响。
- **统计严谨性不足**：未报告标准差或置信区间，70 客户端配置仅运行 1 次；且不同变体未使用完全相同的文件划分和随机种子，导致准确率对比混杂了数据划分差异。
- **缺少与先进方法的系统比较**：仅与原始 SecAgg 和 FedAvg 对比，未与差分隐私、同态加密、可信执行环境等其他隐私保护 FL 方案进行成本/安全性权衡分析。
- **可验证性机制的局限**：辅助公证人的验证标签只覆盖掩码掩码后的聚合值，不验证客户端本地训练过程是否正确执行；恶意客户端仍可提供任意更新，验证只能保证“聚合本身正确”，不能保证“训练行为诚实”。
- **量化与裁剪带来的精度损失**：更新量化至 32 位整数并裁剪，虽设定了合理的尺度因子，但未系统评估不同 τ 和 sQ 对模型收敛和最终精度的影响。
- **记录链接模块未集成评估**：布隆过滤器记录链接作为独立组件提出，未与主联邦学习流程联合实验，其参数选择（布隆大小、哈希数）和相似度阈值对匹配质量的影响完全未知。
