## 摘要
大语言模型的安全防护在回答被使用之前就决定是否回答。这对双用途任务产生了一个基本问题：同一个回答既可以帮助授权专业人员，也可以帮助攻击者，而攻击者可以模仿良性的请求和交互历史。我们将模型释放的能力与有关下游用途的可用证据分开。当该证据是可复制的时，我们推导出在保留有用回答的同时攻击者协助的确切最坏情况下限。结果产生了一个安全三难困境：有用能力、可靠安全性和开放访问不能共存。然后我们展示了可信凭证如何通过添加难以复制的、可预测实际下游用途的信息来补充现有安全防护，并确定了消除该下限所需的更强条件。来自双用途评估、自适应攻击和已部署的可信访问项目的证据支持这些条件的实际相关性。

## Abstract
Large language model safeguards decide whether to answer before seeing how an answer will be used. This creates a basic problem for dual-use tasks: the same answer can help an authorized professional or an attacker, while an attacker can imitate a benign request and interaction history. We separate the capability released by the model from the evidence available about downstream use. When that evidence is copyable, we derive the exact worst-case floor on attacker assistance while preserving useful answers. The result yields a safety trilemma: Useful Capability, Reliable Safety, and Open Access cannot coexist. We then show how a trusted credential can complement existing safeguards by adding hard-to-copy information that predicts actual downstream use, and identify the stronger condition needed to eliminate the floor. Evidence from dual-use evaluations, adaptive attacks, and deployed trusted-access programs supports the practical relevance of these conditions.

## 1. 论文的核心问题与整体含义

- **研究动机**：大型语言模型（LLM）的安全防护机制（如安全训练、请求/响应过滤、安全补全策略）在模型输出被实际使用**之前**就做出决策。然而对于“双用途任务”（dual-use tasks），同一个回答既可以用于合法的专业场景（如授权漏洞评估），也可以用于恶意目的（如策划入侵），而攻击者可以人为地模仿合法用户的请求和交互历史。
- **核心问题**：当安全机制可观察到的上下文（请求、交互历史、声明意图）可以被攻击者完全复制时，模型无法在回答前区分合法与恶意用途，因而存在一个**不可避免的攻击者协助下限**。
- **核心贡献**：论文提出了一个“安全三难困境”（Safety Trilemma）：**有用能力（Useful Capability）、可靠安全性（Reliable Safety）与开放访问（Open Access）三者不可同时兼得**。在此基础上，论文证明引入**可信凭证（Trusted Credential）** 所代表的不可复制信息，可以降低该下限，并指出彻底消除该下限所需的更强条件。

## 2. 论文提出的方法论

- **核心思想**：将模型释放的“能力”与关于“下游用途”的可观测“证据”分离开来分析。若证据可复制，则无论防护策略多复杂，最终都会退化到静态的能力分配问题。

- **关键概念**：
  1. **效用函数**：对每个释放（release）a，定义合法用途效用 `u_B(a)` 与恶意用途效用 `u_M(a)`。
  2. **能力下限 Γ(q)**：在满足合法用途效用至少为 `q` 的所有释放分布中，恶意用途效用的最小值，即 `Γ(q) = min Σμ(a)u_M(a)`，约束条件为 `Σμ(a)u_B(a) ≥ q`。这是与防护机制无关的能力固有属性。
  3. **可复制证据（Copyable Evidence）**：当恶意策略可以完全模拟合法参照策略，使得攻击者诱导出的整个对话历史分布与合法用户的分布相同（即 `P_B ∈ C_κ`），则证据被视为可复制。

- **核心定理**：
  - **Theorem 1（交互到静态的精确约简）**：若证据可复制，任何复杂交互式安全机制的效果退化为一个静态释放菜单，其最坏情况下界恰好等于 `Γ(q)`。
  - **Corollary 1（安全三难困境）**：在双用途条件下，对任意 `q > 0`，若仅依赖可复制证据，则无法同时满足有用能力（效用≥q）、可靠安全（协助≤β<Γ(q)）和开放访问。
  - **Theorem 2（可信凭证的约简）**：引入与下游用途相关的不可复制信号 S 后，最优恶意协助下限变为条件于 S 的 `Γ_S(q)`；交互历史 H 在条件复制前提下不增加额外的最坏情况信息。
  - **Corollary 3（零协助的充要条件）**：`Γ_S(q)=0` 当且仅当合法用途的效用主要集中在恶意进程无法到达的信号值上，即 `q ≤ q_max · P_B(S0)`。
  - **Theorem 3（必要条件）**：对于不完美复制场景，若要达到协助上限 β，必须满足 `β + d + η_κ ≥ Γ(q)`，其中 `d` 为信号 S 区分两种下游用途的统计距离，`η_κ` 为条件复制误差。

- **扩展分析**：论文还讨论了任务族加权、逐轮近似误差、重试与任务分解（证明跨会话的相关性不影响累加下限）、二元目标（一次性成功概率）等场景。
