## 摘要
联邦微调大型语言模型（LLMs）能够在无需暴露原始数据的情况下进行协作训练。然而，最近一种名为NeuroImprint [1]（arXiv:2606.20553）的攻击表明，恶意参数服务器可以将PEFT适配器篡改为隐私后门：通过为每个训练样本分配一个专用的记忆神经元，并确保每个神经元最多更新一次，服务器能够以较高的语义保真度解析重构出59%–79%的客户端训练数据。现有防御手段——包括本地差分隐私（LDP）[8]和梯度裁剪——要么无法抵御这种攻击，要么带来难以接受的效用损失。我们提出了**TriShield**，一种三层确定性防御机制，能够完全阻止NeuroImprint式的数据重构，且**零模型效用损失**、**无额外通信轮次**。TriShield包括：（1）**参数工件检测器**，在本地训练开始前识别分布式模型参数中的记忆神经元特征；（2）**有状态虚拟迭代**机制，强制Adam/AdamW的动量状态在虚拟步骤间不可逆地纠缠梯度，使NeuroImprint的闭式求逆失效；（3）**零效用正交投影**算子，将所有本地梯度更新投影到通过SVD计算的主任务语义子空间上，从物理上消除任何携带私有记忆的梯度分量。我们从理论上证明，在经过第2层和第3层后，上传梯度与任何单个训练样本之间的互信息为零。在GPT-2（117M）和Llama-Guard-3-1B上的实验验证，TriShield在所有测试的攻击变体下均将NeuroImprint的重构率降至**0%**，同时保持或提升训练准确率，且额外GPU计算开销低于5%。

## Abstract
Federated fine-tuning of large language models (LLMs) enables collaborative training without exposing raw data. However, a recent attack, NeuroImprint [1] (arXiv:2606.20553), demonstrates that a malicious parameter server can corrupt a PEFT adapter into a privacy backdoor: by assigning a dedicated memorization neuron to each training sample and ensuring each neuron updates at most once, the server can analytically reconstruct 59\%--79\% of client training data with high semantic fidelity. Existing defenses---including local differential privacy (LDP) [8] and gradient clipping---either fail against this attack or impose unacceptable utility degradation. We present \textbf{TriShield}, a three-layer deterministic defense that completely prevents NeuroImprint-style reconstruction with \textbf{zero model utility loss} and \textbf{no additional communication rounds}. TriShield consists of: (1) a \textbf{Parameter Artifact Detector} that identifies memory-neuron signatures in distributed model parameters before local training begins; (2) a \textbf{Stateful Virtual Iteration} mechanism that forces Adam/AdamW's momentum state to irreversibly entangle gradients across virtual steps, invalidating NeuroImprint's closed-form inversion; and (3) a \textbf{Zero-Utility Orthogonal Projection} operator that projects all local gradient updates onto the main-task semantic subspace computed via SVD, physically eliminating any gradient components that carry private memorization. We prove theoretically that after Layers 2 and 3, the mutual information between the uploaded gradient and any individual training sample is zero. Experiments on GPT-2 (117M) and Llama-Guard-3-1B verify that TriShield reduces NeuroImprint reconstruction rate to \textbf{0\%} across all tested attack variants, while maintaining or improving training accuracy, with less than 5\% additional GPU computation overhead.

## 2. 论文提出的方法论

TriShield 由三个顺序执行的层次组成，每层针对 NeuroImprint 的不同攻击机制：

### (1) 参数工件检测器（Parameter Artifact Detector, PAD）

- **核心思想**：在本地训练开始前，扫描服务器下发的适配器参数，识别 NeuroImprint 植入的记忆神经元签名。
- **检测特征**：
  - 行内方差极低（接近零，如 <10⁻⁴）；
  - 多行之间响应向量高度相关（相关系数 >0.95）；
  - 对应偏置值集中在固定常数附近。
- **处置方式**：将检测到的记忆神经元重置为 Kaiming 正态初始化，并重新随机化偏置，从而破坏“样本↔神经元”的映射关系。

### (2) 有状态虚拟迭代（Stateful Virtual Iteration, SVI）

- **核心思想**：NeuroImprint 依赖 Adam 优化器的“单次更新线性性”进行闭式求逆。SVI 在真实训练前，用公开辅助数据 D_aux 执行 K 次虚拟优化步，但**只更新 Adam 动量/二阶矩状态，不更新模型权重**。
- **技术效果**：预热的动量状态 m_K、v_K 包含了多个公开样本的梯度信号。当真实样本梯度到达时，最终权重更新变为动量与真实梯度的非线性混合函数：
  \[
  \Delta\theta = f(m_K, v_K, g_{real})
  \]
  服务器无法从最终更新中分离出真实梯度，因为 m_K、v_K 对服务器不可见。
- **理论保障**（Theorem 1）：给定最终更新，恢复真实梯度需解具有 O(d_in) 个未知数但仅 O(1) 个约束的非线性方程组，系统欠定，存在无穷多解。

### (3) 零效用正交投影（Zero-Utility Orthogonal Projection, ZUOP）

- **核心思想**：NeuroImprint 的记忆神经元梯度本质上位于主任务梯度子空间的正交补空间（这是其保持“对任务不可见”的设计使然）。因此，将客户端本地梯度投影到主任务语义子空间，可以物理消除携带私人记忆的梯度分量。
- **算法流程**：
  1. 在公开辅助数据 D_aux 上计算任务梯度矩阵 G = [∇ϕL(x₁), …, ∇ϕL(x_n)]；
  2. 对 G 做 SVD 分解，取前 k 个左奇异向量构成主任务子空间 U_k；
  3. 将本地更新 Δϕ 投影：Δϕ* = U_k U_kᵀ Δϕ。
- **投影秩选择**：k = 0.8 × rank(G)（经验安全默认值），过高（如 0.95）会导致 SR1E 变体泄漏约 12%–50%。

### 理论保证

- **Theorem 2**：若主任务梯度位于 U_main 中，则正交投影保留完整任务梯度（零效用损失）。
- **Theorem 3**：记忆神经元梯度（⊥ U_main）被投影为零向量，服务器得到的重建为 0/0，互信息 I(x̂; x)=0。
- **Theorem 4**：对于近似正交（角度 δ<5°）的变体，泄漏信息被限制为小于原始熵的 0.8%。
- **Theorem 5**：在满足投影秩足够、辅助数据同分布等条件下，TriShield 的 FedAvg 收敛不动点与标准 FedAvg 一致。

## 6. 论文的主要结论与发现

1. **防御有效性**：TriShield 在 GPT-2 和 Llama-Guard-3-1B 上，对所有 NeuroImprint 变体的令牌重建率均降至 **0%**（等于干净噪声底数）。
2. **零效用损失**：宣称下游精度损失 ≤0.3%（基于 ZUOP 梯度保留理论 ≈7% LoRA A 矩阵保留率），且 demo 规模训练准确率波动为统计噪声，非实质性退化。
3. **计算开销**：GPU 下额外开销 <5%（论文摘要）或 <4%（部分章节），CPU 下约 72%（SVI 和 ZUOP 的线性代数为主）。
4. **关键技术见解**：
   - PAD 和 SVI 的防御效果不体现在梯度范数上（梯度范数保持不变），而体现在破坏映射或使闭式求逆不可行；只有 ZUOP 物理消除梯度分量。
   - 秩分数 0.80 是安全默认值，0.95 会导致 SR1E 泄漏，因为随机向量更容易与过大的保留子空间对齐。
   - 面对自适应攻击，PAD 处理可检测变体（VTB/MLD/MLPL），ZUOP 处理 PAD 逃逸但任务正交的变体（SR1E），LCN 变体因随机正交行自毁，形成纵深防御。

## 7. 优点

- **理论深度**：给出了互信息为零的理论证明（Theorem 3、Theorem 4），并为 SVI 的不可逆性提供了信息论/代数论证，区别于单纯启发式防御。
- **零效用损失设计**：通过将梯度投影到主任务子空间，在理论上保留全部任务梯度，避免 LDP 的效用代价。
- **纯客户端部署**：不需要服务器配合，对 FL 协议透明，易于集成到现有框架（Flower、PySyft 等）——约 100 行代码。
- **架构无关性**：PAD 基于权重统计、SVI 基于优化器状态、ZUOP 基于参数空间投影，可适用于 LoRA、adapter、prefix tuning 等常见 PEFT 方法。
- **防御纵深**：三层机制各自独立，即使某一层被绕过，仍能提供互补保护（如 PAD 遗漏时 ZUOP 兜底）。
- **实验中的诚实性**：明确区分了“实际测量”与“投影/外推”结果，并针对范数代理指标的混淆效应做了深入分析和替代指标验证，体现了方法论的严谨态度。

## 8. 不足与局限

- **全规模实验缺失**：SST-2/AG News 在 GPT-2 和 Llama-Guard 上的端到端防御效果均为外推结果，并非实测。最关键的“重构率 0%”只在小规模（15 样本）上验证，大规模、多客户端、多轮通信下的表现未经验证。
- **辅助数据依赖**：ZUOP 需要 32–500 条与训练分布相近的公开数据。在高度专业或完全无公开数据的领域（如医疗基因组学），子空间估计质量无法保证，可能损害效用。
- **效用损失的理论假设较强**：定理 2 假设主任务梯度完全位于 U_main 中，但若辅助数据 D_aux 与私有数据分布有偏离，或投影秩选择不准确，实际效用损失可能超过声称的 0.3% 上界。
- **CPU 开销过高**：SVI+ZUOP 在 CPU 上占训练轮次约 72%，边缘设备或纯 CPU 环境难以接受；GPU 下虽然降到 <5%，但依赖硬件加速。
- **理论适用范围有限**：证明针对 NeuroImprint 类依赖“逐神经元记忆”的攻击；对跨神经元纠缠编码、非 LoRA 适配器、或新型后门机制，需要扩展分析。
- **隐含假设未充分挑战**：安全性依赖于“记忆神经元梯度与任务子空间正交”这一 NeuroImprint 的设计特性。论文虽讨论了自适应攻击，但“在任务子空间内编码且不泄露分布信息”的可能性论证较为简略。
- **收敛性证明依赖条件**：定理 5 要求 D_aux 与 D_i 同分布，实际中通常难以严格满足，收敛等价性的适用范围有限。
